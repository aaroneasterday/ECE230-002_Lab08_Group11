## Lab Questions

### In plain English describe the function and use of a multiplexer.
A multiplexer takes multiple inputs and gives one output depending on the inputs.

### In plain English describe the function and use of a demultiplexer.
A demultiplexer takes one input and gives one of many outputs depending on the input.

### What other uses might these circuits have? (Think Shannon’s)
Any of the previous lab activities, as Shannon's states that you can represent any boolean function using multiplexers.
